Shorts Uploader

Satu video, satu klik, terkirim ke semua channel.

Pengaturan koneksi GitHub

Token hanya disimpan di browser ini dan hanya dikirim ke api.github.com. Buatnya sesuai PANDUAN.md.

Vertikal (9:16), durasi di bawah 3 menit, maksimal 70 MB.

Tag #Shorts ditambahkan otomatis ke deskripsi jika belum ada.

Channel tujuan

Judul dan deskripsi tiap channel bisa diubah supaya tidak sama persis. Itu mengurangi risiko dianggap konten duplikat.

Hubungkan GitHub dulu di pengaturan.
